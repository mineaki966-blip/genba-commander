# 現場コマンダー

MCLSのCSCATTTに沿って、多数傷病者事故の指揮を学ぶ訓練ゲームです。

- **C・S・C・A**：写真で現場を調べて根拠カードを集め、指揮ミーティングで隊員の判断を是正する。拠点を地図に配置する。
- **T・T・T**：ターン制の救護所シミュレーション。限られた人員・資器材・救急車で傷病者を救う。
- シナリオは5本（マイクロバス横転／化学工場の有毒ガス漏えい／高速道路の多重衝突／商業施設の火災／列車の脱線）。

> 教育用の架空シナリオです。判定基準は国の基準とMCLSの考え方をもとに簡略化しています。実際の活動は各地域のプロトコルに従ってください。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作る（例：`genba-commander`、Public）
2. このフォルダの中身をすべてアップロードする（`img` と `bgm` フォルダも含める。`.nojekyll` も忘れずに）
3. リポジトリの **Settings → Pages** を開き、Source を `Deploy from a branch`、Branch を `main` / `(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/genba-commander/` で開けるようになる

## スマホへのインストール

- **iPhone**：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chromeで開く → メニュー → 「アプリをインストール」または「ホーム画面に追加」

一度開けば、電波のない場所でも遊べます（BGMだけは通信が必要です）。

## 更新するとき

ファイルを差し替えたら、`sw.js` の1行目付近にある `const VER='gc-v1';` の数字を上げてください（`gc-v2` など）。上げないと、スマホに古い画像が残ることがあります。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム本体 |
| `img/` | 立ち絵・現場写真 |
| `bgm/` | BGM（7曲） |
| `manifest.webmanifest`・`icon-*.png` | ホーム画面に追加するための設定とアイコン |
| `sw.js` | オフラインで遊ぶための仕組み |

途中保存とBGMのオン・オフは、遊んだ端末の中にだけ保存されます。
